Masuk Toko Sembako Budi

Gunakan akun Supabase Anda. Pelanggan dapat mendaftar agar katalog, stok, dan pesanan terhubung ke toko.

Akun pelanggan dan pesanan nyata menggunakan Supabase. Pendaftaran mungkin memerlukan konfirmasi email sebelum Anda dapat masuk. Pratinjau DEMO terpisah (opsional)

Daftar Pelanggan

Akun yang didaftarkan di sini selalu memiliki role pelanggan.

Atur ulang password

Masukkan email akun pelanggan Anda. Jika akun tersedia, Supabase akan mengirim tautan untuk menetapkan password baru.

Tautan pemulihan harus kembali ke alamat aplikasi yang diizinkan pada Supabase Authentication → URL Configuration. Saat aplikasi dibuka sebagai file lokal, Supabase menggunakan Site URL proyek.

Aktifkan Akun

Buat kata sandi untuk menyelesaikan undangan dan mengaktifkan akun Anda.
